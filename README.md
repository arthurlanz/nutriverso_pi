# NutriVita

Site institucional de uma clínica de nutrição fictícia, feito em **HTML, CSS e JavaScript puros**. Foi desenvolvido como Projeto Integrador no IFC Campus Araquari.

## Páginas

- **Início** (`index.html`): apresentação e chamada para os planos
- **Sobre** (`sobre.html`): missão, história e equipe de especialistas
- **Planos** (`planos.html`): planos de acompanhamento e perguntas frequentes
- **Contato** (`contato.html`): canal para falar com a equipe

## Tecnologias

- HTML5 semântico
- CSS3 (metodologia BEM)
- JavaScript

## Como abrir

Não precisa de instalação. Clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/arthurlanz/nutriverso_pi.git
```

## Estrutura

```
index.html · sobre.html · planos.html · contato.html
assets/
├── css/
└── js/
```
